PROJETO SANTANDER — VERSÃO COM ANIMAÇÕES

Como abrir:
1. Extraia todos os arquivos mantendo a pasta img.
2. Abra index.html no navegador.

Arquivos:
- index.html: estrutura e conteúdo da página.
- style.css: layout, identidade visual, responsividade e animações CSS.
- script.js: menu mobile, entrada de elementos ao rolar e parallax discreto.
- img/: imagens e ícones fornecidos no projeto original.

Observações:
- O projeto usa Google Fonts (Inter); se não houver internet, será usada uma fonte alternativa.
- Os links e textos são demonstrativos. Antes de publicar, revise todos os destinos e substitua conteúdo ilustrativo pelo conteúdo oficial aplicável.
- Não foram adicionados formulários nem fluxos de autenticação.
